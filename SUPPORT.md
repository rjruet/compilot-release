# Support

## Before opening an issue

- Confirm you downloaded the newest release.
- Check `SHA256SUMS.txt` if the installer or APK will not open.
- On Windows, include the Windows version, the app name and version, and whether
  **Write anywhere** was on.
- On Android, include the Android version, device model and keyboard version.
- Do not include passwords, API keys, private documents or other secrets.

## Where to ask

Use [Issues](https://github.com/rjruet/compilot-release/issues). Please use the
title prefix `[Windows]`, `[Android]`, or `[Release]`.

Security problems: follow [SECURITY.md](SECURITY.md), not a public issue.

## Compatibility

This is a preview. Notepad, Gmail in Chrome and Microsoft Word are **Untested**
until the project records a real UI pass. Other apps may expose no text field to
Windows Accessibility and will be skipped rather than guessed.
